# Speaker CV Documents
Place speakers' PDF CVs in this directory.

### Naming Convention:
Use clean slugified names with speaker ID or name:
- `dr-ahmed-alqahtani-cv.pdf`
- `dr-sara-mohammed-cv.pdf`

### Database Link:
In the database `[Speakers]` table, store the path as:
`~/Content/docs/speakers/dr-ahmed-alqahtani-cv.pdf`
