# Speaker Photos & Avatars
Place speakers' profile photos in this directory.

### Recommended Specifications:
- **Format:** `.jpg`, `.png`, or `.webp`
- **Dimensions:** Square aspect ratio (minimum `600x600px`, ideally `800x800px`)
- **Naming Convention:**
  - `dr-ahmed-alqahtani.jpg`
  - `dr-sara-mohammed.jpg`

### Database Link:
In the database `[Speakers]` table, store the path as:
`~/Content/images/speakers/dr-ahmed-alqahtani.jpg`
